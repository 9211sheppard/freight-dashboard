============================================
  WFA Contacts Dashboard — Team Setup
============================================

FIRST TIME SETUP (do this once)
────────────────────────────────
1. Extract this zip to your Desktop
2. Double-click:  setup.bat
3. Wait for it to finish (installs automatically)
4. Double-click:  run.bat
5. Browser opens automatically → log in

LOGIN PASSWORD:  admin123


EVERY TIME YOU USE IT
──────────────────────
1. Double-click run.bat on your Desktop
2. Browser opens to http://127.0.0.1:5000
3. Log in and search


LOADING NEW DATA (when you receive a CSV by email)
───────────────────────────────────────────────────
1. Save the CSV file anywhere on your computer
   (e.g. Downloads folder)
2. Open the dashboard (run.bat)
3. Click the yellow  [Import CSV]  button (top right)
4. Select the CSV file you saved
5. Done — data updates instantly


REQUIREMENTS
─────────────
- Windows 10 or 11
- Python 3.9+  (free download: https://www.python.org/downloads/)
  ⚠ During install tick "Add Python to PATH"


NEED HELP?
───────────
Contact your dashboard administrator.
