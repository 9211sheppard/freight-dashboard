About ELD Integration

How It Works
  • Set the provider's API key as an environment variable
  • Click "Sync Now" to pull current HOS clock data
  • Driver HOS records are stored in the local database
  • Violations and remaining hours are tracked per driver
  • Real-time sync requires a valid paid API subscription
FMCSA Compliance
  • ELD mandate applies to most CMV drivers (49 CFR Part 395)
  • 11-hour driving limit / 14-hour on-duty window
  • 30-minute break required after 8 hours driving
  • 70-hour limit in 8 consecutive days
  • Logs must be available for roadside inspection
