Security at Freight Intelligence

Our Security Commitments
  • All data encrypted in transit (TLS/HSTS) and at rest (AES-256)
  • Multi-factor authentication (TOTP) with backup codes
  • Role-based access control with granular per-feature permissions
  • SOC 2-ready audit logging and quarterly access reviews
  • Session fingerprinting and anomaly detection
  • Password breach detection via HaveIBeenPwned
  • Content Security Policy with per-request nonces
  • API authentication with scoped, expiring keys
