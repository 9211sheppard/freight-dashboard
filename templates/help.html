Help & Documentation

What is Freight Intelligence?
It is a freight operations dashboard that combines contact data, vessel schedules, rate workflows, outreach tracking, agent scoring, and guided learning in one place.

How to create an account
Open /register, create your user profile, and sign in. The first registered user becomes an admin automatically.

How to import your first CSV
Click the yellow Import CSV button in the top-right navbar, choose your file, and let the dashboard map common freight contact columns.

Understanding the dashboard layout
The top navbar holds global actions like Learn, Help, CSV import, refresh, team invites, and logout. The tab strip below it switches between Contacts, Schedules, Rates, Outreach, and Agents for admins.

Searching contacts
Use the filters to search by company, contact name, country, network, or email availability. You can also sort by company or country and export filtered results to CSV.

Importing CSV files
Supported files typically include columns such as company_name, contact_name, email, phone, country, city, website, and network.

Exporting contacts to CSV
Apply the filters you want, then click Export CSV to download the current result set.

Contact networks
Common network tags include WFA, WWPC, FIATA, Freightnet, WCA, and AHK-Japan. Use the network buttons to narrow the contact list quickly.

Browsing schedules by origin and destination
Start by selecting an origin region, then choose a destination region to load available sailings and lane coverage.

Understanding carrier badges and colors
Each carrier uses a distinct badge color so you can scan results faster when comparing sailings on the same lane.

Filtering by carrier and vessel name
Once a lane is selected, use the carrier dropdown or vessel search box to narrow the results.

Predictive ETAs and what they mean
Predicted ETAs estimate likely arrival timing using historical schedule performance. They help surface likely delay patterns before a vessel arrives.

Which lanes have data
The destination pills show where a selected origin already has schedule coverage so you can avoid empty lanes quickly.

Reliability grades explained
Grades from A+ through F summarize on-time performance, delay consistency, and recent voyage history for each carrier or lane.

Rate cycles
A rate cycle groups one round of requests, responses, follow-ups, and benchmarking for a date range or campaign.

Sending rate requests to agents
Choose the contacts and lanes you want, then send rate requests to your network for the current cycle.

Parsing rate replies from email
The dashboard can capture structured rate details from agent emails and link them back to the relevant cycle and lane.

Benchmarks
Floor, mid, and max values show the pricing spread for each lane so you can spot outliers quickly.

Agent nudging system
Nudges help follow up with agents who have not replied or whose pricing sits well outside the typical market range.

Rate trends
Use cycle history to compare how rates are moving over time by lane, carrier, or participating agent.

Email campaigns overview
Outreach keeps a record of who you contacted, when messages were sent, and how agents responded.

Tracking replies and responses
Use reply tracking to see follow-up status, response timing, and which contacts still need attention.

Introduction emails
Use introduction outreach when you are warming up a contact before a rate cycle or relationship handoff.

Agent scoring methodology
Scores combine response time, data quality, consistency, and lane coverage so admins can compare partners on more than price alone.

Nudge engine rules
The nudge engine highlights slow responses, thin lane participation, and unusual pricing behavior that needs follow-up.

Self-recovery system
Agents can recover from flags over time as they submit clean, timely, and consistent data in future cycles.

Flagged agents
Use the flagged view to review partners with repeated data quality or responsiveness issues before assigning new work.

Changing your password
Use the password reset flow if you forgot your password, or change it from the logged-in account tools if that action is enabled for your role.

User roles
admin users can invite team members and access Agents. user accounts can work with the main freight data pages without admin controls.

Inviting team members
Admins can use Add User in the navbar to send an invite by email or direct teammates to register at /register.

Quick search
On the Contacts page, start typing in the search filters immediately to narrow results.

Import CSV
Use the yellow navbar button whenever you receive a fresh contact export. The importer expects a header row and UTF-8 CSV format.

Learn mode
Click Learn in the navbar to start interactive training sessions without leaving the application.
